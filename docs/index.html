Score de recommandation — 3 méthodologies

La qualité perçue d'un fournisseur n'existe pas dans le catalogue brut. Plutôt que d'en inventer une, trois méthodes sont calculées et comparées, chacune avec sa couverture réelle et ses limites. Ces scores portent sur le catalogue complet et ne suivent pas les filtres : la qualité d'un fournisseur ne change pas selon qu'on regarde ses offres 4G ou 5G.

Composante éditoriale = score publié par MyBestSim, pondération d'origine conservée (60 % éditorial, 16 % prix, 14 % couverture, 10 % réseau 5G). Disponible pour 5 fournisseurs sur 18 — les autres sont marqués indisponibles plutôt qu'estimés.
Composante éditoriale = note Trustpilot rescalée sur 100, retenue uniquement au-delà de 2 500 avis pour écarter les échantillons non représentatifs. 12 fournisseurs sur 18 couverts.
Aucune composante éditoriale : seuls les 3 critères mesurables dans le catalogue, repondérés à 100 % en conservant leurs poids relatifs d'origine (40 % prix, 35 % couverture, 25 % réseau 5G). Seule version couvrant les 18 fournisseurs.
