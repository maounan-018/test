Score de recommandation — 3 méthodologies

Le score éditorial (qualité perçue) n'est pas présent dans le catalogue brut — trois façons de le traiter sont comparées ci-dessous plutôt qu'une seule présentée comme vérité.

Éditorial = score officiel publié par MyBestSim (mybestsim.com), pondération 60% éditorial / 16% prix / 14% couverture / 10% réseau 5G. Disponible pour 5 des 18 fournisseurs seulement — les autres sont marqués indisponibles plutôt qu'estimés.
Éditorial = note Trustpilot (rescalée /100), retenue uniquement au-delà de 2 500 avis pour garantir un échantillon représentatif. 12 des 18 fournisseurs couverts ; les 6 restants (moins de 2 500 avis, ou match produit incertain pour Instabridge) sont marqués indisponibles.
Aucune composante éditoriale — uniquement les 3 critères quantifiables du catalogue, pondération rescalée à 100% (40% prix / 35% couverture / 25% réseau 5G) à partir des poids relatifs de MyBestSim. Couvre les 18 fournisseurs sans exception.
